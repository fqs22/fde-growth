## 1. 产品概述

### 1.1 一句话定位
一套**通用**的「内容获客 → 私域孵化 → 付费转化」全链路工具平台，以 AI 生成与数据分析为核心能力；
**行业知识、画像字段、话术与合规规则均可按行业包配置**，一套系统适配多行业。

### 1.2 为什么要通用化（2026-10-24 决策）
| 维度 | 只做澳洲移民 | 通用平台 + 行业包（选定） |
|---|---|---|
| 与 JD 契合 | 偏离（JD 要求家庭教育 / 商业培训方向） | 契合：证明搭建通用 AI 系统的能力 |
| 产品思维体现 | 弱（定制工具） | 强（配置化、可扩展，打 JD 第 3 条「产品化思维」） |
| 落地说服力 | 有真实数据，但面窄 | 澳洲移民作为**首个已落地行业包**，用真实数据说话 |
| 成本 | 低 | 增加约 15%-20% 配置化设计工作量 |

### 1.3 业务目标
1. 降低小红书内容生产成本（选题→成文从半天降至 30 分钟内）。
2. 提升私信→加微→签约的转化率（漏斗各环节可视化、可优化）。
3. 客户资产沉淀：客户画像、跟进记录、知识库全部结构化留存。

### 1.4 目标用户
| 角色 | 说明 |
|---|---|
| 超级个体（主用户） | 本人：内容创作、客户跟进、成交一体化 |
| 顾问/助理（预留） | 后续可分配跟进任务、查看客户档案 |

### 1.5 行业包（Vertical Pack）机制 —— 通用化的核心
一个行业包 = 一套配置 + 一份知识，切换行业只需换包，不动平台代码。

| 行业包组成 | 内容 | 澳洲移民包示例 |
|---|---|---|
| 关键词矩阵 | 人群 × 痛点 × 品类的关键词库 | 澳洲移民、482/189/190/491、雇主担保、留学移民 |
| 知识库 | 结构化知识卡 + 常见问题 + 案例，向量化供 RAG | 签证类别知识卡、政策要点、成功案例 |
| 画像字段模板 | 该行业客户要采集的字段 | 签证意向、签证/毕业到期时间、预算区间、学历职业 |
| 话术与序列模板 | 高频问答、异议处理、Drip 序列种子内容 | 费用/周期/成功率边界表述、D1-D14 跟进序列 |
| 合规规则 | 该行业禁用词与表述红线 | 「保签」「100% 成功」「内部通道」 |
| 漏斗阶段定义 | 该行业的转化阶段命名 | 曝光→私信→加微→评估→报价→签约 |

> 后续可扩展行业包：家庭教育、商业培训（**与 JD 方向一致，可作为第二个包**）、留学、保险等。

### 1.6 与岗位 JD 的映射（求职叙事主线）

> ✅ 已验证：以下「JD 要求」为真实 JD 原文（来源：JD 截图原文件，2026-10-24 读取确认）。

| 热点/对标数据 | 手动录入；P2 浏览器插件半自动采集 | 无公开 API，爬虫有封号风险 → 不采用 |
| 私信 | 无法 API 读取 | 转化链路从「加微」起计量 |

> 📌 数据模型需支持「账号维度」（专业号/个人号），看板可按账号筛选。
> **导入适配器模式**：所有外部数据统一走「文件导入 → 解析 → 入库」，未来开放 API 仅需新增适配器，上层不变（求职亮点架构决策）。
