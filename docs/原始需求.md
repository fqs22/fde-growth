**岗位**：AI 产品经理搭建师 FDE 知识付费

**岗位职责：**
1. 负责 AI 系统在知识付费领域的搭建与优化，聚焦家庭教育及商业培训方向；

3. 搭建智能化内容分发与用户成长体系，实现课程产品与用户需求的精准匹配；
4. 协同内容与运营团队，完成从流量获取到付费转化的全链路系统部署。

**任职要求：**
1. 熟悉 AI 工具与自动化系统搭建，具备知识付费行业项目经验；
2. 精通 FDE 模型逻辑，有成功落地的用户增长案例；

## 六、账号与工具现状（2026-10-24 已确认）

- **小红书**：持有 **专业号** + **普通个人号**；**投放过广告**（平台待确认：聚光 / 蒲公英）。
- **企业微信**：**已完成企业验证**（可用自建应用 API、渠道活码、客户朋友圈 API）。
- **会话存档**：原由企微内的 **探马 SCRM（ERP）** 提供 → **已停止续费，不再使用**。
  企微官方会话存档报价 900 元/账号/年（服务版，最低 5 账号起购），**决策暂不开通** → 改用手动补录聊天要点。

## 七、产品定位决策（2026-10-24）

- 平台定位为 **通用** 的「小红书获客 → 企微私域转化」平台，**行业可插拔**（行业包机制：关键词 / 知识库 / 画像字段 / 话术序列 / 合规规则 / 漏斗阶段）。
- **澳洲移民咨询 = 首个落地行业包**（真实业务，提供验证与演示数据）。
- 后续可扩展行业包：家庭教育、商业培训等（与岗位 JD 方向一致）。
- 因探马停用，私域侧（客户管理、SOP、朋友圈发布、画像评分、漏斗归因）**全部由本平台自建 + 企微原生 API 承担**。
