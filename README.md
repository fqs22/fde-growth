# FDE-Growth

小红书获客 × 企业微信私域转化平台（澳洲移民咨询业务实战项目）

## 项目定位
面向移民咨询 / 知识付费类业务的「内容获客 → 私域孵化 → 付费转化」全链路工具平台，
以 AI 生成与数据分析为核心能力，对标岗位：AI 产品经理搭建师 FDE · 知识付费方向。
