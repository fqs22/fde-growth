# FDE-Growth

通用的「小红书获客 × 企业微信私域转化」全链路平台（行业可插拔）

## 项目定位
一套**通用**的「内容获客 → 私域孵化 → 付费转化」工具平台，以 AI 生成与数据分析为核心能力。
行业知识、客户画像字段、话术序列、合规规则、漏斗阶段全部通过**行业包（Vertical Pack）**配置，
一套系统适配多行业。

- **首个落地行业包**：澳洲移民咨询（真实业务，用于验证闭环与演示数据）
- 可扩展：家庭教育、商业培训、留学等
- 对标岗位：AI 产品经理搭建师 FDE · 知识付费方向
